
# Hãy giúp tôi phân biệt npm run dev và npm run build? Tôi chưa hiểu là khi chạy từng lệnh này thì nó sẽ thực sự làm gì?

**`npm run dev` chạy app để bạn lập trình trên máy mình, còn `npm run build` đóng gói app thành các file tĩnh để đưa lên mạng.** Hai lệnh được khai báo trong [package.json:7-8](package.json#L7-L8):

```json
"dev": "vite",
"build": "tsc -b && vite build"
```

## `npm run dev`
Lệnh này bật một server trên máy bạn và **chạy liên tục cho đến khi bạn nhấn `Ctrl + C`**.

```text
1. Vite mở server tại http://localhost:5173
2. Trình duyệt xin index.html, rồi xin tiếp /src/main.tsx
3. Trình duyệt không hiểu TSX, nên Vite dịch file đó sang JavaScript ngay lúc được xin
4. main.tsx import App.tsx, trình duyệt lại xin App.tsx, cứ thế đến hết các file cần dùng
5. Khi bạn lưu một file, Vite báo trình duyệt cập nhật phần vừa đổi
```

Vite dịch từng file khi cần nên khởi động rất nhanh, và lệnh này **không tạo thư mục `dist/`**.

## `npm run build`
Lệnh này **chạy một lần rồi kết thúc**, gồm hai bước nối bằng `&&`, nghĩa là bước 1 phải thành công thì bước 2 mới chạy:

```text
Bước 1: tsc -b      → kiểm tra kiểu TypeScript toàn bộ code. Có lỗi thì dừng luôn
Bước 2: vite build  → gom code và thư viện lại, nén nhỏ, rồi ghi ra dist/
```

Lần build trước của dự án này đã gom 430 module thành 3 file chính:

```text
index.html                 0.72 kB
assets/index-BAIetgiC.css  33.09 kB
assets/index-OWZRqfnH.js   385.07 kB
```

Phần chữ lạ trong tên file (`BAIetgiC`) được tạo từ nội dung file. Khi code đổi, tên file cũng đổi, nên trình duyệt của người dùng không bị dùng nhầm bản cũ đã lưu.

Sau khi build xong, không có server nào đang chạy và `dist/` chỉ là một thư mục chứa file.

## So sánh nhanh

| | `npm run dev` | `npm run build` |
|---|---|---|
| **Dùng khi** | Đang viết code | Chuẩn bị deploy |
| **Thời gian chạy** | Chạy liên tục | Xong rồi tự kết thúc |
| **Tạo `dist/`** | Không | Có |
| **Kiểm tra lỗi kiểu TypeScript** | Không | Có |
| **Tự cập nhật khi sửa code** | Có | Không, phải build lại |
| **Code gửi tới trình duyệt** | Nhiều file nhỏ, dễ debug | Ít file, đã nén, tải nhanh |

## Ba điều người mới hay nhầm
1. **Dev chạy được chưa chắc build được.** Khi dev, Vite chỉ bỏ phần kiểu đi chứ không kiểm tra. Ví dụ, dòng `const x: number = 'abc'` vẫn chạy bình thường ở dev, nhưng làm `npm run build` thất bại.
2. **Sửa code xong, `dist/` không tự đổi.** Bạn phải chạy `npm run build` lại.
3. **Đừng mở `dist/index.html` bằng cách bấm đúp.** App sẽ không chạy được vì file này cần được phục vụ qua một server. Muốn xem thử bản build, hãy chạy `npm run preview`, thường ở địa chỉ `http://localhost:4173`.

## Tự kiểm chứng
Mở DevTools, vào tab **Network**, rồi tải lại trang trong từng trường hợp:

- **Với `npm run dev`:** bạn sẽ thấy nhiều file riêng như `main.tsx`, `App.tsx`, `GameScreen.tsx`.
- **Với `npm run build` rồi `npm run preview`:** các file đó không còn nữa, chỉ còn một file JS và một file CSS trong `assets/`, cùng với font.

Quy trình thường ngày là dùng `npm run dev` khi viết code, rồi chạy `npm run build` trước khi deploy. Các dịch vụ như Vercel hay Netlify cũng chạy build rồi đưa `dist/` lên mạng cho mọi người truy cập.
